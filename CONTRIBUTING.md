# Contributing

Thank you for helping improve Nuvi-Flow.

1. Create a focused branch.
2. Run `npm ci`, `npm test`, `npm run typecheck`, and `npm run build`.
3. Do not include media files, databases, `.env` files, passwords, stream tokens, or private filesystem paths.
4. Explain user-visible behavior and verification in the pull request.

Bug reports should include the operating system, deployment method, app version, sanitized logs, and a representative filename with personal path segments removed.
